## 关键发现

1. **连续状态 > 离散状态**：cont.ft32 (88.1%@50k → 93.0%@80k) 全面碾压 ft32 (72.1%)，且随训练推进持续提升
2. **ft64 异军突起**：ft64@60k (77.6%) 超越 ft16@50k (75.5%)，goal 84.6% / object 89.2% 尤其亮眼。ft 维度大未必差
3. **ft0 与 ft16 持平**：ft0@50k (72.9%) vs ft16@50k (75.5%)，差距仅 2.6%，ft=0 的低维策略在某些场景不输 ft=16
4. **libero_10 仍是短板**：所有实验 10 最低（39%~69%），多步长时序任务挑战最大
5. **spatial 普遍偏高**：5 组实验 spatial 均 ≥87%，说明空间推理任务相对饱和
6. **object 趋于收敛**：多组实验 object 达 85-100%，满分 task 增多，pick-place 类任务接近饱和
7. **cont.ft32 持续增长**：50k→80k，平均 88.1%→93.0%，longer training 持续有效
