# 为 StarVLA 做贡献

StarVLA 由社区为社区而建。以下是参与方式：

- **报告 Bug** — 提交 [Issue](https://github.com/starVLA/starVLA/issues)。如需更多上下文，可发起 Discussion。
- **提议功能或改进** — 在提交 PR 前，请通过 Issue 或[合作表单](https://forms.gle/R4VvgiVveULibTCCA)进行简短同步来对齐范围。
- **需要帮助或想头脑风暴？** — 填写[合作表单](https://forms.gle/R4VvgiVveULibTCCA)。我们每周五下午举办办公时间答疑。
- **提交 PR 前**，在修改的文件上运行 Black + Ruff（仓库目前有历史 lint 积压，因此全仓库 `make check` 预期会失败；参见 [PR_readme.md](PR_readme.md#4-提交前检查清单)）。
